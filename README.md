
# 🏪 Super-store Sales Report (Power BI)

This project is a **Power BI dashboard** built to analyze the sales performance of a fictional Super-store.  
The report provides insights into **sales trends, profit analysis, regional performance, and product category contributions**, helping businesses make data-driven decisions.

---

## ✨ Key Features
- 📊 **Sales & Profit Analysis**: Track overall sales and profit distribution.  
- 🌍 **Regional Insights**: Visual breakdown of performance by region and state.  
- 📦 **Category & Sub-category Analysis**: Compare sales across Furniture, Office Supplies, and Technology.  
- ⏳ **Time Series Trends**: Monthly and yearly performance tracking.  
- 🛒 **Customer & Order Analysis**: Understand customer behavior and order patterns.

## 🚀 Getting Started

### 1. Prerequisites
- Install **Power BI Desktop** (free from Microsoft Store or official site).

### 2. Open the Report
1. Clone this repository or download it as a ZIP.  
2. Open `store sales.pbix` in Power BI Desktop.  
3. Explore the interactive dashboard using filters and visuals.  

---

## 📚 Dashboard Highlights
The dashboard includes:
- **KPIs**: Total Sales, Total Profit, Discount %, Order Count  
- **Charts**:  
  - Sales vs Profit by Category & Sub-category  
  - Regional sales distribution (map view)  
  - Monthly/Yearly trends  
  - Top 10 profitable and unprofitable products
